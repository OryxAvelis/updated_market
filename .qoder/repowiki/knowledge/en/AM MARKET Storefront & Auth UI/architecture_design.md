Two HTML entry points share a common runtime loaded in order: `js/i18n.js` then `js/app.js`. `index.html` is a single-page application where each route (home, shop, detail, cart, checkout, orders, wishlist) is a sibling `<section class='view'>` inside `#mainContent`, toggled via a central `showView(name)` function that adds/removes the `.active` class. `login.html` is a standalone auth page with inline handlers for login/signup form switching, validation, and user persistence. Both pages load Bootstrap 5.3.3 CSS/JS bundle, Font Awesome 6.5.1, Google Fonts (Inter), and a favicon. The i18n module (`i18n.js`) centralizes all EN/FR strings in an `I18N` object, exposes `t(key, vars)` with `{var}` interpolation, persists language in `localStorage` under `am_lang`, applies translations at DOM level via `data-i18n`, `data-i18n-html`, `data-i18n-ph`, `data-i18n-title` attributes, and dispatches an `am:langchange` CustomEvent that consumers (e.g., login page brand copy) subscribe to. `app.js` defines SPA routing, fetches live categories/products from `https://api.mmarket.ma/api`, caches product detail responses, and persists cart/wishlist/orders/recently-viewed lists under fixed `localStorage` keys (`am_cart`, `am_wish`, `am_orders`, `am_recent`). Styling is split across `css/style.css` (storefront layout, cards, hero banner, mobile tabbar) and `css/login.css` (split-brand auth card). There is no build step — files are served directly from the repository root over HTTP.
